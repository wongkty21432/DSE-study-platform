# 跨篇比較與文化意涵（比較題必備）

比較題要**兩者兼論**，逐點講異同 + 理據，唔可以只答「有/無共通處」。

## 一、思想流派比較
| 篇章 | 流派 | 核心主張 |
|------|------|----------|
| 論仁論孝論君子 | 儒家 | 仁為最高道德，落實於孝與君子人格 |
| 魚我所欲也 | 儒家（孟子） | 性善，捨生取義，保持本心 |
| 勸學 | 儒家（荀子） | 性惡（須後天學習改造），學不可以已 |
| 逍遙遊 | 道家（莊子） | 突破世俗束縛，無用之用，逍遙自由 |
| 出師表 | 奏表 | 忠君報國，親賢遠佞 |
| 六國論 | 史論 | 借古諷今，反對屈辱求和 |

### ⭐ 孟子 vs 荀子（人性論對比）
| | 孟子（魚我所欲也） | 荀子（勸學） |
|--|------------------|--------------|
| 人性觀 | **性善**（本心有善端） | **性惡**（需後天改造） |
| 教育作用 | 存養本心，勿喪失 | 化性起偽，改變本質 |
| 落腳點 | 捨生取義 | 學不可以已 |

### ⭐ 儒家 vs 道家
- 儒家：**入世**（修身、齊家、治國）→ 仁、義、孝、學
- 道家：**出世**（超脫世俗）→ 無為、逍遙、齊物

## 二、寫作手法跨篇比較
| 手法 | 篇章舉例 |
|------|----------|
| 比喻論證 | 魚我所欲也（魚熊掌）、勸學（青出於藍）、六國論（抱薪救火） |
| 對比論證 | 論仁（君子小人）、師說（古今）、六國論（賂/不賂） |
| 借景抒情 | 始得西山宴遊記、岳陽樓記、登樓、山居秋暝 |
| 借古諷今 | 六國論（北宋）、登樓（後主）、出師表（先漢後漢） |
| 卒章顯志 | 岳陽樓記、六國論、始得西山宴遊記 |
| 寓言 | 逍遙遊（鯤鵬、大瓠大樗） |

## 三、風格比較（詩詞）
| 篇章 | 作者 | 風格定位 |
|------|------|----------|
| 山居秋暝 | 王維 | 山水田園，**詩中有畫** |
| 月下獨酌 | 李白 | **浪漫主義**，想像奇特 |
| 登樓 | 杜甫 | **現實主義**，沉鬱頓挫 |
| 念奴嬌・赤壁懷古 | 蘇軾 | **豪放** |
| 聲聲慢 | 李清照 | **婉約**（疊字） |
| 青玉案・元夕 | 辛棄疾 | 豪放中帶婉約（反襯） |

## 四、答比較題的機械流程
```
1. 拆題：比較「邊兩方面」？（思想／手法／風格／人物）
2. 分點：開對照點（異 / 同）
3. 舉例：每點舉出雙方的文本例證
4. 小結：指出差異根源（流派 / 處境 / 目的）
```

## 五、易錯點
- ❗ 只講一方，冇真正比較
- ❗ 只答「有共通處」而唔解說
- ❗ 抽離文本空談流派
