# 《逍遙遊》（節錄）（莊子）

> **主旨**：通過鯤鵬與蜩學鳩的對比，及「無用之用」的討論，說明人要**突破世俗觀念的束縛**、轉換思考角度，才能達到**絕對自由的逍遙境界**。

## 一、結構層次
```
1. 鯤化為鵬，海運徙南冥 → 極寫鵬之大與高遠
2. 蜩與學鳩譏笑大鵬 → 「小知不及大知，小年不及大年」
3. 大小之辯：朝菌、蟪蛄、冥靈、大椿
4. 惠子與莊子論「無用」→ 大瓠、大樗的「無用之用」
```

## 二、必背名句 ⭐
- 「**北冥有魚，其名為鯤。**鯤之大，不知其幾千里也。」
- 「**怒而飛，其翼若垂天之雲。**」
- 「**摶扶搖而上者九萬里**，去以六月息者也。」
- 「**小知不及大知，小年不及大年。**」
- 「舉世譽之而不加勸，舉世非之而不加沮。」
- 「**無用之用**」（大樗「不夭斤斧，物無害者」）

## 三、寫作手法
| 手法 | 例 |
|------|----|
| **寓言** | 鯤鵬、蜩學鳩、大瓠大樗 |
| **對比** | 大（鵬）vs 小（蜩學鳩）；大年 vs 小年 |
| **誇張** | 鵬「不知其幾千里」「垂天之雲」 |
| **比喻** | 以物喻人／喻理 |

## 四、高頻考問
1. 鯤鵬的形象有何寓意？
2. 蜩與學鳩的譏笑說明了什麼？
3. 「小知不及大知，小年不及大年」的深層意思
4. 莊子如何論證「無用之用」？
5. 本文如何體現莊子的逍遙思想？

## 五、易錯點
- ❗ 「摶」＝盤旋而上，非「搏」
- ❗ 「志怪者也」的「志」＝記述
- ❗ 誤解「無用之用」為「完全冇用」；正解＝**看似無用實為大用**
- ❗ 勿將莊子的「逍遙」等同消極避世
