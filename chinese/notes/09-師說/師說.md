# 《師說》（韓愈）

> **主旨**：論證**從師學習的必要性**，批判當時「恥學於師」的風氣，並提出「**道之所存，師之所存**」的主張。

## 一、結構層次
```
1. 立論：古之學者必有師（師者，傳道授業解惑）
2. 反駁：批判「恥學於師」的時弊
3. 對比：古之聖人 vs 今之眾人；愛其子 vs 於其身
4. 舉例：孔子師郯子、萇弘、師襄、老聃
5. 結論：弟子不必不如師，聞道有先後
```

## 二、必背名句 ⭐
- 「**古之學者必有師。師者，所以傳道、受業、解惑也。**」
- 「**人非生而知之者，孰能無惑？**」
- 「**道之所存，師之所存也。**」
- 「**今之眾人，其下聖人也亦遠矣，而恥學於師。**」
- 「**愛其子，擇師而教之；於其身也，則恥師焉，惑矣！**」
- 「**是故無貴無賤，無長無少，道之所存，師之所存也。**」
- 「**弟子不必不如師，師不必賢於弟子。聞道有先後，術業有專攻。**」
- 孔子曰：「**三人行，則必有我師。**」

## 三、寫作手法
| 手法 | 例 |
|------|----|
| **對比論證** | 古聖 vs 今眾；愛子擇師 vs 自身恥師；巫醫樂師 vs 士大夫 |
| **舉例論證** | 孔子師郯子等 |
| **引用論證** | 引孔子「三人行必有我師」 |
| **排比／頂真** | 「道之所存，師之所存」句式迴環 |

## 五、易錯點
- ❗ 「**受業**」＝傳授學業（「受」通「授」）
- ❗ 「**所以**」＝用來…的／…的原因（視句）
- ❗ 「**惑矣**」＝糊塗啊（非「疑惑」）
- ❗ 「恥學於師」＝以向老師學習為恥（意動用法）
