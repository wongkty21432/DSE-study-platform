# 《始得西山宴遊記》（柳宗元）

> **主旨**：記述發現及遊覽西山的經過，以「**始得**」點明西山之遊帶來前所未有的精神解脫——**心凝形釋，與萬化冥合**，抒發貶謫心境下的超然體悟。

## 一、結構層次
```
1. 記未得西山前的宴遊 → 遊遍諸山，「以為凡是州之山有異態者，皆我有也」
2. 發現西山 → 「始指異之」，過湘江、緣染溪、斫榛莽
3. 登西山所見 → 極寫高遠：「尺寸千里」「縈青繚白」
4. 登覽感受 → 「心凝形釋，與萬化冥合」→ 點出「始得」
```

## 二、必背名句 ⭐
- 「**凡是州之山水有異態者，皆我有也，而未始知西山之怪特。**」
- 「**過湘江，緣染溪，斫榛莽，焚茅茷**，窮山之高而止。」
- 「**攀援而登，箕踞而遨，則凡數州之土壤，皆在衽席之下。**」
- 「**尺寸千里，攢蹙累積，莫得遯隱。**」
- 「**縈青繚白，外與天際，四望如一。**」
- 「**然後知吾嚮之未始遊，遊於是乎始。**」
- 「**心凝形釋，與萬化冥合。**」

## 三、寫作手法
- **借景抒情／寓情於景**：以開闊之景寫精神解脫
- **對比**：遊諸山 vs 遊西山（前後心境對比）
- **移步換景**：隨遊蹤描寫所見
- **象徵**：西山「怪特」自比孤高不屈

## 四、高頻考問
1. 「始得」二字的深意（為何之前的遊不算「遊」？）
2. 「心凝形釋，與萬化冥合」是什麼境界？
3. 本文如何運用對比？
4. 西山的形象與作者處境的關係
5. 借景抒情手法如何體現？

## 五、易錯點
- ❗ 「**僇人**」＝受刑戮的罪人（柳宗元自稱被貶）
- ❗ 「**衽席**」＝坐臥之席；「尺寸千里」＝咫尺間見千里之景
- ❗ 「與萬化**冥合**」＝與萬物渾然融為一體
- ❗ 注意「遊於是乎始」＝**真正的遊覽從此才開始**
