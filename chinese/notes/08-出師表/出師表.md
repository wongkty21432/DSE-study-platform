# 《出師表》（諸葛亮）

> **主旨**：勸諫後主劉禪**親賢遠佞**、勵精圖治，並表明自己「**報先帝、忠陛下**」的忠心及北伐決心。

## 一、結構層次
```
1. 論天下形勢 → 說明北伐必要（危急存亡之秋）
2. 進諫三項建議 → 廣開言路、賞罰分明、親賢遠佞
3. 自述生平 → 三顧草廬、臨危受命（表明忠心）
4. 表明決心 → 願"鞠躬盡瘁"，並囑後主自謀
```

## 二、必背名句 ⭐
- 「**苟全性命於亂世，不求聞達於諸侯。**」
- 「**受任於敗軍之際，奉命於危難之間。**」
- 「**先帝不以臣卑鄙，猥自枉屈，三顧臣於草廬之中。**」
- 「**今南方已定，兵甲已足，當獎率三軍，北定中原。**」
- 「**親賢臣，遠小人，此先漢所以興隆也；親小人，遠賢臣，此後漢所以傾頹也。**」
- 「**陟罰臧否，不宜異同。**」
- 「**此臣所以報先帝而忠陛下之職分也。**」
- 「**願陛下託臣以討賊興復之效；不效，則治臣之罪。**」

## 三、寫作手法
- **議論＋抒情＋敍事** 三結合
- **正反對比**：先漢興隆 vs 後漢傾頹
- **借古諷今**：以先帝事例規勸
- **措辭委婉得體**：以臣子身分諫君，情理兼備

## 四、高頻考問
1. 諸葛亮向後主提出哪三項建議？
2. 為何「親賢遠佞」是全文核心？
3. 諸葛亮如何自述身世以表明忠心？
4. 本文議論與抒情如何結合？
5. 諸葛亮「忠君」思想的具體表現

## 五、易錯點
- ❗ 「**卑鄙**」＝地位低微、見識短淺（非人格卑劣）
- ❗ 「**痛恨**」＝痛心遺憾（非憎恨）
- ❗ 「**不求聞達**」的「聞達」＝顯達揚名
- ❗ 三顧草廬是**劉備**三顧，勿寫成諸葛亮求見
- ❗ 勿將《登樓》（杜甫）內容混入本文
