# 機械式答題流程

## ① 閱讀理解題（乙部）
```
1. 讀題幹 → 圈關鍵詞（問咩？字數限制？）
2. 定位   → 搵返文本對應段落
3. 擷取   → 篩走無關內容，只取重點
4. 改寫   → 用自己的文字概括（唔抄原文）
5. 檢查   → 有無回應題幹所有要求？有無文本依據？
```

## ② 命題寫作（卷二乙部）
```
1. 審題 → 圈題目關鍵詞、體裁、字數
2. 立意 → 定明確立場／中心思想（唔好模糊）★最致命
3. 選材 → 揀獨特／深刻的素材（忌沙灘足印、父母偏心）
4. 佈局 → 分段，輕重有致，段落要有內在關聯
5. 落筆 → 描寫細膩／論證飽滿／關鍵處點題
6. 覆檢 → 錯別字、標點、格式
```

## ③ 實用寫作（卷二甲部）
```
1. 認身分 → 我係邊個？（措辭、自謙語要啱）
2. 認對象 → 寫俾邊個？語氣要啱
3. 認目的 → 要達成咩任務？
4. 整合   → 用晒提供資料（篩走無關材料）
5. 拓展   → 引申意義（普遍弱項）
6. 論證   → 立場＋論據＋論證（三者齊）
7. 格式   → 稱謂／問候／收結／署名／日期（按文體）
8. 字數   → 唔好超標
```

## ④ 範文題（甲部）
```
1. 認篇章 → 題目問邊篇？（忌張冠李戴，如《出師表》混《登樓》）
2. 解字詞 → 實詞＋虛詞按句法判定，唔好靠日常意思猜
3. 語譯   → 補出省略主語/賓語，譯出反問/被動語氣，寫通順白話
4. 手法   → 舉例 + 說明效果（三部分齊）
5. 主旨   → 扣緊文化意涵（儒／道／忠／隱逸…）
```
