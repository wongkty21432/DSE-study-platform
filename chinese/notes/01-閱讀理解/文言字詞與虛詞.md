# 文言字詞與虛詞（死穴）

## 虛詞六大天王（必分清楚）
| 字 | 常見作用 | 例 |
|----|----------|----|
| 之 | ①代詞 ②助詞「的」 ③取消句子獨立性 ④動詞「去」 | 師道之不傳也久矣（取消獨立性） |
| 其 | ①代詞 ②語氣副詞（大概/難道） ③指示「那」 | 其皆出於此乎（大概） |
| 以 | ①用/拿 ②因為 ③憑 ④以致 | 以地事秦（用/拿） |
| 於 | ①在 ②對 ③比 ④被 | 青於藍（比） |
| 而 | ①並列 ②轉折 ③承接 ④修飾 | 青取之於藍而青於藍（轉折） |
| 乃 | ①就/於是 ②竟然 ③是 | 乃不知有漢（竟然） |

## 高頻易錯實詞
| 字詞 | 錯誤理解 ❌ | 正解 ✅ |
|------|------------|--------|
| 悉 | 熟悉 | **全部** |
| 卑鄙（出師表） | 人格卑劣 | **地位低微、見識短淺** |
| 痛恨（出師表） | 憎恨 | **痛心遺憾** |
| 所以（師說） | 因果 | **…的憑藉 / …的原因**（視句） |
| 微（岳陽樓記） | 微小 | **如果沒有** |
| 僇人（西山） | 侮辱 | **罪人（受刑戮之人）** |
| 假（勸學） | 虛假 | **憑藉** |

## 三個必判技巧
1. **通假字**：辟＝避（魚我所欲也）｜受＝授（師說）｜生＝性（勸學）
2. **詞類活用**：名詞作動詞、形容詞作名詞
3. **一字多義**：靠**句法／詞性**判斷，**唔好死記，唔好靠日常意思猜**

## 考生通病
- ❗ 只按日常意思猜（「悉」解熟悉）
- ❗ 改動字形部件：「囑」寫「屬」、「咐」寫「付」
- ❗ 虛詞只記單一義，一成不變
