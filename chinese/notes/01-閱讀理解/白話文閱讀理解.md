# 白話文閱讀理解

## 答題五步（背熟）
```
讀題幹→圈關鍵詞 → 定位段落 → 擷取重點 → 自己文字改寫 → 覆核（要求+依據）
```

## 三類必考題
| 題類 | 做法 |
|------|------|
| 內容理解 | 定位原文，篩走無關，**自己文字**概括 |
| 手法/效果 | **舉例 ＋ 說明效果 ＋ 扣緊文本**（三部分） |
| 深層寓意/主旨 | 由表面文意推至象徵、主旨，**綜合全文** |

## 反問／比較／評價題
- 反問句：要譯出反問語氣，睇清問嘅係「認同定反對」
- 比較題：**兩者兼論**，逐點講異同，唔可以只答「有/無共通處」
- 評價題：立場 ＋ 文本依據（唔可以純個人感想）

## 通病（考生表現報告）
- ❗ 審題不周 —— 漏睇「起伏／原因／表現／轉換點／目的」
- ❗ 只抓單一段落 → 未綜合全文
- ❗ 就個人聯想發揮（「人生就是一場長跑…」）而無文本依據
- ❗ 答案蕪雜：抄多餘原文反被扣分
