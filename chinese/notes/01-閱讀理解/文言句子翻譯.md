# 文言句子翻譯（語譯）

## 四大陷阱
1. **被動句漏譯**：「見…」「為…所…」「被」→ 譯出「被」義
2. **省略句**：主語、賓語省略 → **一定要補回**
3. **反問句**：要譯出反問語氣（「怎會」「哪裡」「難道」）
4. **用詞不精準**：「何」唔可以譯「何其」「何等」

## 評分要求
- 逐字對譯 **唔夠分**
- 要寫成 **通順現代漢語句子**
- 意思準確 ＋ 語法通順，兩者兼得

## 機械流程
```
1. 圈出關鍵實詞 → 逐個準確譯
2. 判斷句式   → 被動 / 省略 / 反問 / 倒裝
3. 補回省略   → 主語、賓語、介詞
4. 串成白話   → 讀一次，通唔通順？
5. 檢查      → 有無漏字、語序有無調正
```

## 例
> 「志士仁人，無求生以害仁，有殺身以成仁。」
→ 有志之士和仁德之人，**不會**為了求生而損害仁德，**只會**犧牲生命來成全仁德。
（注意「無…有…」＝「不會…只會…」的對舉）
