# 《魚我所欲也》（孟子）

> **主旨**：以魚與熊掌比喻生與義的取捨，說明**義重於生**，「捨生取義」出於人的**本心**（性善），並告誡人勿見利忘義、喪失本心。

## 一、結構層次
```
1. 以魚熊掌為喻 → 引出「捨生取義」
2. 正反論證：所欲有甚於生 / 所惡有甚於死
3. 由「本心」推論：人人本有捨生取義之心
4. 反面批判：受物欲所蔽而「失其本心」
```

## 二、必背名句 ⭐
- 「魚，我所欲也，熊掌，亦我所欲也；二者不可得兼，**舍魚而取熊掌者也**。」
- 「生亦我所欲也，義亦我所欲也；二者不可得兼，**舍生而取義者也**。」
- 「生亦我所欲，**所欲有甚於生者**，故不為苟得也。」
- 「**非獨賢者有是心也，人皆有之**，賢者能勿喪耳。」
- 「一簞食，一豆羹，得之則生，弗得則死。」
- 「**萬鍾則不辯禮義而受之**，萬鍾於我何加焉！」
- 「此之謂**失其本心**。」

## 三、寫作手法
| 手法 | 例 |
|------|----|
| **比喻論證** | 以魚熊掌喻生義 |
| **對比論證** | 生 vs 義；賢者 vs 常人 |
| **正反立論** | 所欲有甚於生 / 苟得 |
| 排比 | 「鄉為身死而不受，今為宮室之美為之…」 |
| 設問 | 「何不用也？」「何不為也？」 |

## 四、高頻考問

2. 為什麼「捨生取義」是出於「本心」？

## 五、易錯點
- ❗ 「辟」＝避（通假），非「開闢」
- ❗ 「勿喪耳」＝不要喪失（本心），非「死」
- ❗ 「萬鍾」指優厚俸祿，非「一萬種」
- ❗ 誤把「本心」解作「原本的想法」，正解＝**天賦的善性**
