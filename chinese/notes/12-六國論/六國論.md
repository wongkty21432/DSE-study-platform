# 《六國論》（蘇洵）

> **主旨**：借六國賂秦而亡的史實，**借古諷今**，諷刺北宋對遼、西夏的屈辱外交（輸幣求和），警告當朝勿重蹈覆轍。

## 一、結構層次
```
1. 提出中心論點：六國破滅，弊在賂秦
2. 申論：賂秦者力虧（以地事秦，猶抱薪救火）
3. 反面論證：不賂者（齊燕趙）亦以失援而亡
4. 假設論證：若六國各愛其地、合力抗秦，未必亡
5. 借古諷今：苟以天下之大，下而從六國破亡之故事
```

## 二、必背名句 ⭐
- 「**六國破滅，非兵不利，戰不善，弊在賂秦。**」
- 「**賂秦而力虧，破滅之道也。**」
- 「**以地事秦，猶抱薪救火**，薪不盡，火不滅。」
- 「**古人云：『以地事秦，猶抱薪救火，薪不盡，火不滅。』此言得之。**」
- 「**苟以天下之大，下而從六國破亡之故事，是又在六國下矣！**」
- 「**燕趙之君，始有遠略，能守其土，義不賂秦。**」
- 「且燕趙處秦革滅殆盡之際，可謂**智力孤危**，戰敗而亡，**誠不得已**。」

## 三、寫作手法
| 手法 | 例 |
|------|----|
| **借古諷今** | 借六國喻北宋 |
| **論證手法** | 舉例、比喻（抱薪救火）、引用、假設、對比 |
| **對比** | 賂秦者（韓魏楚）vs 不賂者（齊燕趙） |
| **設問／反問** | 「六國互喪，率賂秦耶？」 |
| **卒章顯志** | 末句點出諷今之意 |

## 四、高頻考問
1. 六國破滅的原因是什麼？
2. 「抱薪救火」的比喻說明了什麼？
3. 蘇洵如何運用假設論證？
4. 「借古諷今」針對北宋什麼政策？
5. 本文的論證層次

## 五、易錯點
- ❗ 本文**不只**寫六國，重點在**諷今（北宋）**
- ❗ 「革滅」＝被消滅；「智力孤危」＝謀略與國力單薄
- ❗ 「故事」＝舊事、前例（非「故事書」）
- ❗ 勿把「賂秦」與「不賂秦」兩類混淆
