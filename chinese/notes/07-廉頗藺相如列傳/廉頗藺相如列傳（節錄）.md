# 《廉頗藺相如列傳》（節錄）（司馬遷）

> **主旨**：透過「完璧歸趙」「澠池之會」「負荊請罪」三事，刻劃**藺相如**（智勇雙全、顧全大局）與**廉頗**（勇於改過）的高尚品格。

## 一、三事結構
```
1. 完璧歸趙 → 藺相如機智勇敢、不畏強秦
2. 澠池之會 → 藺相如據理力爭、維護國威
3. 負荊請罪 → 廉頗知錯能改；藺相如以國事為重
```

## 二、人物形象
| 人物 | 性格 | 塑造手法 |
|------|------|----------|
| 藺相如 | 機智、勇敢、忠心、忍辱負重、顧全大局 | 語言、動作、側面烘托 |
| 廉頗 | 勇猛、率直、**勇於改過**、顧全大局 | 對話、行動（負荊請罪） |
| 秦昭王 | 恃強凌弱、反覆無常 | 對比反襯 |

## 三、必背名句 ⭐
- 「臣以為**布衣之交尚不相欺**，況大國乎！」
- 「**臣頭今與璧俱碎於柱矣！**」
- 「今兩虎共鬥，其勢不俱生。吾所以為此者，**以先國家之急而後私讎也。**」
- 「**強秦之所以不敢加兵於趙者，徒以吾兩人在也。**」
- 廉頗：「**鄙賤之人，不知將軍寬之至此也！**」

## 四、寫作手法
- **敘事剪裁**：三事詳略得當，突出人物
- **語言／動作描寫**：藺相如「持璧睨柱」、廉頗「負荊」
- **對比／反襯**：藺相如 vs 秦王的狡詐；藺相如的大度 vs 廉頗的狹隘（後轉變）
- **側面描寫**：以秦「不敢加兵」襯藺相如之功

## 五、高頻考問
1. 「完璧歸趙」中藺相如如何表現智勇？
2. 藺相如為何屢次退讓（避廉頗）？
3. 廉頗的形象轉變及意義
4. 本文運用了哪些人物塑造手法？
5. 三件事之間的內在聯繫

## 六、易錯點
- ❗ 「負荊請罪」的「負」＝背負，非「辜負」
- ❗ 藺相如避讓非懼怕廉頗，而是**先國家之急**
- ❗ 「璧」＝和氏璧，非泛指玉器
