# 《勸學》（節錄）（荀子）

> **主旨**：論證**學習不可停止**，強調**後天學習**能改變人的本質，並須專心致志、持之以恆。

## 一、結構層次
```
1. 提出中心論點：學不可以已
2. 學習的意義與作用：青出於藍、冰寒於水、木受繩則直
3. 學習能改變本質：君子博學日參省 → 知明行無過
4. 學習須善假於物：登高、順風、假輿馬、假舟楫
5. 學習須專心致志：蚓 vs 蟹；騏驥 vs 駑馬
```

## 二、必背名句 ⭐
- 「**學不可以已。**」
- 「**青，取之於藍，而青於藍**；冰，水為之，而寒於水。」
- 「木直中繩，輮以為輪，其曲中規。」
- 「**君子博學而日參省乎己，則知明而行無過矣。**」
- 「吾嘗**終日而思矣，不如須臾之所學也**。」
- 「**君子生非異也，善假於物也。**」
- 「**鍥而不舍，金石可鏤**；鍥而舍之，朽木不折。」
- 「**不積跬步，無以至千里**；不積小流，無以成江海。」
- 「騏驥一躍，不能十步；**駑馬十駕，功在不舍**。」
- 「蚓無爪牙之利…**用心一也**；蟹六跪而二螯…**用心躁也**。」

## 三、寫作手法
| 手法 | 例 |
|------|----|
| **比喻論證** | 青出於藍、冰寒於水、登高、假舟楫 |
| **對比論證** | 騏驥 vs 駑馬；蚓 vs 蟹 |
| **排比／對偶** | 不積跬步…不積小流… |
| 引用 | 引《詩經》「尸鳩在桑」 |

## 四、高頻考問
1. 「青出於藍」比喻什麼？
2. 「善假於物」的意思及舉例
3. 文中如何論證「鍥而不舍」？
4. 對比手法（蚓／蟹、騏驥／駑馬）的作用
5. 荀子與孟子在人性論上的差異，如何反映於本文？

## 五、易錯點
- ❗ 「生非異也」的「生」＝性（通假）
- ❗ 「假」＝憑藉、借助，非「虛假」
- ❗ 「跬步」＝半步；「十駕」＝十天走的路程
- ❗ 「參省」＝檢驗省察
