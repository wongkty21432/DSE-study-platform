# 甲部：實用寫作（30%）

## 四大評分支柱
1. **語境意識** — 身分、對象、目的、場合
2. **整合拓展** — 整合資料 ＋ **拓展意義（普遍弱項）**
3. **見解論證** — 立場 ＋ 論據 ＋ 論證
4. **表達組織** — 格式、結構、用詞

## 常見文體格式
| 文體 | 格式要點 |
|------|----------|
| 書信 | 稱謂**頂格**、問候語、正文、祝頌語、署名、日期 |
| 演講辭 | 稱謂（頂格）、問候、自報身分、正文、收結致謝 |
| 建議書 | 標題、稱謂、引言、建議（分點）、結語、署名日期 |
| 報導 | 標題、導語、正文（倒金字塔）、署名 |

## 常犯錯誤（考生表現報告）
- ❗ **格式錯**：稱謂、祝頌語、署名日期擺錯或漏
- ❗ **身分／對象搞錯** → 措辭不當
- ❗ **自謙語用錯**變自大（忽略主語所指角色）
- ❗ **整合 vs 拓展失衡** → 只有整合，無拓展意義
- ❗ **見解論證薄弱** → 有見解無論據，或有論據無論證
- ❗ **張冠李戴**：用錯／抄錯資料
- ❗ **字數超標**（多有上限，如 550 字）

## 機械流程
```
認身分→認對象→認目的→整合(用晒) →拓展(引伸) →論證(立場+論據+論證) →格式 →字數
```
