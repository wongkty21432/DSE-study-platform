# 記叙／描寫文技巧

## 描寫四法
| 手法 | 要點 |
|------|------|
| 外貌 | 抓特徵，避「濃眉大眼」等套語 |
| 語言 | 符合身分性格，令人「聞聲見人」 |
| 行為 | 用細節動作代替形容詞 |
| 心理 | 直接剖白 / 透過動作環境折射 |

## 描寫要「抓特點」
- 觀察 ＋ 詞彙 = 描寫力
- 用具體代替空泛：`「萬頭攢動」 > 「人山人海」`
- 五感（視聽嗅觸味）＋ 遠近／動靜／虛實

## 記叙文佈局
```
起（懸念/場景）→ 承（鋪展衝突）→ 轉（轉折/頓悟）→ 合（餘韻/昇華）
```
- 忌流水帳，要**詳略得宜**
- 高潮位置預留筆墨（避免前重後輕）

## 常見失分
- 描寫粗疏、欠缺觀察
- 情節公式化、題材雷同
- 只記叙不昇華（無中心）
