# 議論文技巧

## 三段骨架（每段一個論點）
```
論點句 → 闡釋 → 舉例（精準） → 論證分析（扣題） → 小結
```

## 立論三要求
1. 立場明確（唔好兩邊遊走）
2. 層次分明（由淺入深 / 正反 / 個人→群體）
3. 論證飽滿（分析邏輯，非堆砌）

## 論據
| 類型 | 例 |
|------|----|
| 事實論據 | 歷史、時事、數據 |
| 道理論據 | 名言、原理、常理 |
| 比喻論據 | 類比說理 |

## 通病
- ❗ 例貴多不貴精（以為多例＝高說服力）
- ❗ 例子不當（與論點無關）
- ❗ 以偏概全、單一角度
- ❗ 推論過於直接，欠解釋說明
- ❗ 只有見解無論據 / 有論據無論證

## 進階手法
- 駁論：先提出對方觀點再反駁（「或曰…然則…」）
- 反面論證：假設不這樣做會如何
