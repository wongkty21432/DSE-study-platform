# 《岳陽樓記》（范仲淹）

> **主旨**：藉描寫岳陽樓的陰晴景色與遷客騷人的不同感受，抒發「**不以物喜，不以己悲**」的胸襟，提出「**先天下之憂而憂，後天下之樂而樂**」的政治理想。

## 一、結構層次
```
1. 記敍重修岳陽樓的緣起（受託作記）
2. 總寫岳陽樓之景（洞庭湖「銜遠山，吞長江」）
3. 分寫：霪雨霏霏之悲 vs 春和景明之喜
4. 由景及情 → 古仁人之心
5. 點出主旨：先憂後樂
```

## 二、必背名句 ⭐
- 「**銜遠山，吞長江，浩浩湯湯，橫無際涯。**」
- 「**不以物喜，不以己悲。**」
- 「**居廟堂之高則憂其民，處江湖之遠則憂其君。**」
- 「**是進亦憂，退亦憂。然則何時而樂耶？**」
- 「**先天下之憂而憂，後天下之樂而樂。**」
- 「**微斯人，吾誰與歸？**」
- 寫景對句：「**浮光躍金，靜影沉璧**」「**長煙一空，皓月千里**」

## 三、寫作手法
| 手法 | 例 |
|------|----|
| **借景抒情** | 陰雨景→悲；晴朗景→喜 |
| **對比** | 霪雨霏霏 vs 春和景明（兩種景、兩種情） |
| **駢散結合** | 駢句寫景（對偶工整）＋散句議論（自由） |
| **對偶／疊字** | 「浩浩湯湯」「浮光躍金／靜影沉璧」 |
| **卒章顯志** | 末段點出先憂後樂 |

## 四、高頻考問
1. 兩種景物描寫分別營造什麼氣氛？引出什麼情感？
2. 「不以物喜，不以己悲」的含意
3. 「先憂後樂」如何體現古仁人之心？
4. 本文駢散結合的特色
5. 范仲淹的政治抱負

## 五、易錯點
- ❗ 「**微**斯人」的「微」＝如果沒有
- ❗ 「**去國懷鄉**」＝離開國都、懷念家鄉
- ❗ 「**廟堂**」＝朝廷；「**江湖**」＝民間／貶謫之地
- ❗ 「先天下之憂而憂」勿寫成「先天下之樂而樂」
